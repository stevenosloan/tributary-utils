# utils

Public Go module, standard library only. Versioned by git tag with semantic
versioning (currently `v0.x`).

- Any change that touches exported API, behavior, or `go.mod` must end in a new
  version tag. Use the `release` skill (`.claude/skills/release/SKILL.md`) to
  pick the bump and tag it; don't tag by hand.
- This repo is public: keep secrets, private URLs, and references to private
  repos out of it.
